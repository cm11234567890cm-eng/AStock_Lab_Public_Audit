# Publication and dependency boundary

The repository owner authorized this independent snapshot for public code review. No general-purpose open-source license has been invented or applied to the owner's code. Availability for reading is not a statement that every downstream redistribution or commercial use is licensed; request separate permission for uses beyond the authorized review.

No third-party package source, wheel, executable, native DLL, commercial dataset, or original market-data response is distributed here. Dependencies are named in requirements files and retain their upstream licenses and terms. Installing a package does not grant market-data redistribution rights.

References in original code to data-provider schemas, exchange rules, or package APIs are retained where needed to understand behavior. Data-acquisition permissions and the validity of those rules are separate from this snapshot's publication gate.

Excluded categories include original Git history/author metadata; all original data and historical result files; personal environment configuration; authentication configuration and credentials; historical report generators or fixture builders carrying empirical values; and tests requiring restricted real-data evidence. Exact selected-file dispositions are in FILE_MANIFEST.json. No source algorithm was silently replaced with a simplified implementation.

The review may examine the owner's research thresholds and ranking logic because the owner explicitly authorized publication of this code-review snapshot. Original strategy performance reports, trained models, and empirical cohorts remain excluded.
